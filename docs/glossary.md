| Term | Meaning |
| --- | --- |
| Node | A named proxy outbound that connects to a specific server. |
| Selector | A sing-box outbound that manages a group of nodes and uses the selected node for new traffic. |
| Preview | A loopback proxy that runs in the foreground of a terminal. |
| Loopback service | An opt-in proxy managed by macOS launchd across login sessions. |
| Protected system mode | System TUN plus an independent PF filter and watchdog. |
| Preset | An optional group of destination domains routed to the selected proxy. |
| TUN | A virtual network interface used for transparent system routing. |
